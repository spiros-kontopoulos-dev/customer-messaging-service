# Production issue

Support has escalated an issue in the restaurant messaging service.

A small number of repeat customers say the agent occasionally suggests the wrong "usual" order when they message a store. The reports seem to involve customers who have ordered from more than one location of the same restaurant brand.

One report says a customer messaged the Downtown location and asked for "my usual", but the agent suggested an item the customer had most recently ordered from Riverside instead. The response still named the Downtown store, which made the result especially confusing.

## Your task

Investigate the issue and implement a safe, focused fix.

Please:

- reproduce or otherwise establish the root cause;
- preserve the current API contract unless a change is necessary;
- add or update tests that demonstrate the expected behavior;
- avoid unrelated refactors;
- leave the repository in a state you would be comfortable defending in a code review.

You are not expected to make every possible improvement to the service.
